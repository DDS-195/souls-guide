# 第二次排障整改结果

截至 2026-09-02，第二次审阅中的发布阻断项和主要工程缺口已完成代码整改。

| 范围 | 结果 |
|---|---|
| 默认管理员/JWT | seed 移除固定管理员；生产强制安全初始化密码与 JWT 长度；支持改密和旧令牌失效 |
| HTTPS/真实 IP | 新增生产 Compose/TLS Nginx、HSTS/安全头、受限代理跳数 |
| 上传所有权 | 新增 `upload_assets`、`post_assets`、绑定校验、延迟回收与主动撤销临时资产 |
| 事务一致性 | 文章、审核、申请、公告、排序、互动、评论、用户删除均纳入事务/计数重算 |
| 内容可见性 | 非 published 不可公开详情、互动、评论或举报；公开 DTO 不含正文/驳回原因 |
| 视频 | 合并 MD5、ffprobe 检测、检测式转码、并发信号量、临时目录和孤儿资产定时清理 |
| 前端闭环 | 评论回复/删除、系统通知、媒体撤销、首页/搜索/通知/作品/评论分页、按 ID 编辑回填、重型编辑器按端按需加载；业务代码显式 `any` 清零并由 ESLint 阻止回归 |
| 数据库 | 版本化 migration、常用联合索引、幂等初始化表、删除未使用 FULLTEXT |
| 测试 | 独立 `_test` 数据库自动创建/销毁；当前 160 项后端回归通过 |
| 契约/CI | 仓库内 OpenAPI；测试双向核对 Express 路由；GitHub Actions 覆盖前后端和镜像构建 |
| 运维 | 最小权限应用数据库用户、请求 ID、日志压缩/保留、数据库+uploads 备份恢复脚本；备份原子落盘、限定保留目录，恢复前校验压缩包与路径 |

仍需在目标部署环境完成而不能由当前机器替代的验证：真实域名证书、Docker 三容器启动、真实视频转码质量/耗时、备份恢复演练、磁盘和 CPU 告警接入。项目仍应定位为经过系统加固的学习型 MVP，而不是宣称已具备多机高可用或零停机发布能力。
