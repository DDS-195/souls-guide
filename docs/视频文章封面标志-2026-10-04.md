# 视频文章封面标志

## 实现范围

- 有视频的文章在封面正中央显示半透明深色圆形与白色播放符号；纯图文不显示。
- 首页、搜索、收藏、关注动态、成功补齐数据的历史记录，以及作者主页保持一致。
- 桌面、手机与作者主页的小封面采用不同尺寸，均不占用布局空间。
- 标志不拦截点击，点击封面仍进入文章详情；不会自动播放或预加载视频。
- 后端列表新增真正的布尔字段 `has_video`，通过关联媒体的 `EXISTS` 查询实时计算，不新增数据库字段，也不逐篇请求详情。
- 列表总数与数据查询共用显式筛选条件，避免新增子查询的 `FROM` 导致原计数 SQL 截取错误；多视频不重复文章，移除视频后标志立即消失。
