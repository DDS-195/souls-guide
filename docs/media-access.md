# 上传媒体访问规则（2026-09-14）

本规则替代此前“所有 /uploads 文件直接公开缓存 7 天”的约定。

## 可见性

- 当前头像、游戏封面、已发布文章的封面及关联媒体可以匿名读取。
- 临时上传、草稿、待审、被拒绝文章的关联媒体只允许所有者或管理员读取。
- 失效账号、token_version 已变更的凭证不能读取私有媒体。
- 未登记且没有业务引用的文件、视频分片目录与隐藏文件不对外提供；统一返回 404，避免暴露私有文件是否存在。
- 同一文件若仍被其他已发布文章、头像或游戏封面引用，仍属于公开资源。仅撤回一个引用不会让共享文件变成私有。

## 浏览器预览凭证

图片和原生 video 元素不能自动附加 API 的 Authorization 请求头，因此使用独立的只读媒体凭证。

- 已鉴权响应提供 `X-Media-Grant`。它由 JWT_SECRET 派生的独立密钥签名，audience 为 media-read，最长有效期 15 分钟，不超过来源登录令牌的剩余有效期。
- 前端仅在响应仍属于当前会话时接收凭证；登录后补拉用户资料取得凭证。过期请求和其他标签页已经退出的会话不会重新安装凭证。
- 浏览器将凭证放入 `sg_media` cookie，Path=/uploads，SameSite=Strict；HTTPS 下设置 Secure。cookie 可由 JS 清除，未设 HttpOnly；现有 API 登录凭证本来也由 JS 管理。
- 退出登录立即移除此 cookie；后端仍按每次请求查库校验角色、封禁状态和 token_version。媒体凭证不能作为 API Bearer token 使用，API 不接受 cookie 鉴权。
- 保持登录且页面可见时，已有通知轮询请求会续期；每次已鉴权 API 请求也会续期。

## 服务与缓存

nginx 将 /uploads 请求交给后端先鉴权，再由 express.static 提供文件及 GET/HEAD/Range 支持。响应为 private, no-store，禁用 ETag 和 Last-Modified，避免文章下架后通过新缓存响应继续读取。

旧版本已缓存到用户设备上的文件、下载副本无法远程撤回。访问控制保证的是更新后请求的授权边界，而非数字版权保护。

当前实现为小规模部署采用后端文件流，每次媒体请求会查询数据库；流量增长后可改为 nginx auth_request + 内部文件服务或对象存储短期授权，不得恢复无条件公开静态目录。
